# Digital Certificate Authentication System
MATLAB-based digital certificate authentication using LSB and DCT techniques.

## Project Overview
A MATLAB-based application that authenticates digital certificates using digital watermarking techniques by embedding and verifying unique Certificate IDs.

## Technologies Used
- MATLAB
- MATLAB App Designer
- Digital Image Processing

## Techniques Used
- Least Significant Bit (LSB)
- Discrete Cosine Transform (DCT)

## Key Features
- Certificate ID embedding.
- Watermark extraction and verification.
- Similarity calculation.
- Certificate tampering detection.
- Support for LSB and DCT methods.
